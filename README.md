# PDFツールボックス

PDFのパスワード設定・ロック解除・ページ編集を、ブラウザの中だけで行うツールです。
ファイルは外部に送信されません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動作します） |
| `sw.js` | オフライン対応（任意。なくても動きます） |
| `.nojekyll` | GitHub Pages に「そのまま公開する」と伝える空ファイル |
| `robots.txt` | 検索エンジン向けの設定 |

## 更新するとき

`index.html` を差し替えるときは、先頭付近の次の値も書き換えてください。
利用者に「新しいバージョンがあります」と案内するための目印です。

```html
<meta name="app-version" content="2026-10-24.8">
```
